# 不能说

**一局没有中立仲裁者的海龟汤。它给你讲一个说不通的故事，然后满屋子的人开始互相拆台。**

> Game Jam 主题：它有自己的想法

![截图](docs/screenshot.png)

海龟汤的规矩是：主持人知道答案，你问是非题，他照实答。这一局没有那个主持人。
有的是一屋子各怀立场的证人。**答案的分布本身才是信息。**

汤面、往事、证人、每个人捏着的把柄、考题、答案，连那幅画，都是它在开局那一分钟里
自己想出来的。**没有一局是同一个故事。**

## 上手

```bash
git clone https://github.com/droidlyx/Vibejam_01_lyx
cd Vibejam_01_lyx
python -m http.server 5173
```

打开 `localhost:5173`，右上角**设置**填 DeepSeek API Key（只存在你自己的 localStorage 里）。
等它想四五十秒，一局就开始了。

**没有 Key 就没有游戏**——这是有意的：这里没有任何预先写好的剧情可以退回去。
想先看看长什么样，`localhost:5173/?demo` 是免 API 的渲染自检页。

## 怎么玩

### 1. 它先讲一个说不通的故事

> 颛顼十四年铸成的司辰铜牛，在郕城守时四年，从未漏过一瞬。四年里每逢卯时三刻，
> 它就抖——抖得铁板铆钉跟着颤。今早它又抖了，第三条腿里掉出来一样东西，
> 湿的，温的，不沾一滴油。**来收废铁的赊账人蹲下看了一眼，起身把自己的外褂脱下来，盖了上去。**

这段叫**汤面**。每一句都是真的，整局不变，是你唯一的地基。
它可以瞒，但不能推翻自己讲过的话。

### 2. 你说一句话，点名要谁回答

```
问谁   [胡济民、祁曼生的信标、那支注射器]
问什么 [那天夜里屋里不止一个人           ]

  胡济民        [是]   三个。一直三个。到有人不呼吸为止。
  祁曼生的信标  [是]   不止。但我的频道只有一个——那个频道里只有两个人。
  那支注射器    [是]   不止。多出来的那个，没碰过我。

  表了态：胡济民、祁曼生的信标、那支注射器　｜　花掉 3 次（3／10）
```

三个都答「是」，三个说的不是同一件事——**该盯的是这个**。

「问什么」怎么写都行：问句、说法、猜测。它会归成一句能判真假的命题记进本子。
**只有你点到的人会答**，点几个算几次。

四档裁决：

| | 意思 |
|---|---|
| **是 / 不是** | 按它自己的算盘给，不按实情给 |
| **无关** | "我够不着这件事"——这划的是它的知识边界，**而且不收你的钱** |
| **不能说** | 最响的一档：你压到了它捏着的那件事上，它张不开口 |

### 3. 名单外的人，你自己问出来

起手只给 3 个证人，那不是名单，是三个抓手。

```
问谁   [那个当时在场的医生]
问什么 [他签过什么字      ]
    → 陈时医　人　给铜牛验过伤的那位　进了证人席
```

它来决定这个人在这个故事里存不存在——**而它在这件事上也可以撒谎**。
证人席没有人数上限。能从汤面里推出一个没摆上桌、故事里却确实站得住的人，
是这一局最漂亮的一步。

「它周围的空气」「医生的影子」这种不算，会被当场驳回。

### 4. 它自己也在名单上

「问谁」空着就是在问它。它跟证人同一套规矩：点了才答，答了收费。
区别只有两条：

- **它封不了自己的口。** 别人都可能哑，它永远在。
- **它答的话里有三成是假的。**

### 5. 你问得越多，它掐掉的嘴越多

累计问到 10 个人次，它就出手一次：**让一个证人从此闭嘴**，从你点得最多的那几个里挑。
那一个以后问什么都只剩一格黑，换个叫法也撬不开。

答「无关」的、撞在封过的口上的、问了个不存在的东西的，都不扣你额度。
**只有真给了立场的才计费。**

### 6. 摊牌

题目 3–5 道，由它出，加起来正好等于「汤面为什么说得通」。

一次填完，一次判完，**全部答对才算过**。不告诉你对了几道，
只给一句它听完之后的反应，和一条模糊的接近度。

没全对不结束，罚的不是时间是**提问额度**：摊一次牌等于问了三次，
它照样会因此掐掉一张嘴。答案留着，随时可以再摊一次。

```
┌────────────────────────────┬─────────────┐
│                            │             │
│    汤面那一刻的插图         │   对话      │
│                            │             │
├────────────────────────────┴─────────────┤
│ 问谁 [卡杜、马马杜  ] 问什么 [门是谁锁的] 问│

```

底下那排点一下就填进「问谁」，名单外的直接打字；第一个「它」是它自己，
右边挂着已经被封口的。每问一句，回答底下跟一行回执：

```
表了态：卡杜、马马杜　｜　答「无关」：记谱的木条（不收你的）　｜　封着：更夫　｜　花掉 2 次（7／10）
```

记录全在**本子**里（顶栏按钮或 Tab 键）：

![本子](docs/board.png)

按问题分组，不按证人分组——这个游戏的证据单位是「同一句话上的分歧」。
点上面的名字可以只看单个证人，前后矛不矛盾一目了然；筛「它」就能把它说过的话
排成一列对账。

# 它是怎么做出来的

## 一、没有中立仲裁者，所以立场必须真的咬人

每个证人开局被封存了四样东西：`mind`（它自己想要什么）、`toward`（跟「它」的关系）、
`stake`（它在故事里的位置）、`slip`（它捏着而「它」不想让你知道的一件事）。

裁决从这四样里长出来，不是写死的规则：

- **帮它的**：凡是对「它」不利的真话，一律正面答「不是」。不拿「无关」躲——躲太软
- **恨它的**：同样的真话答得干脆刻薄；替「它」说好话的命题，宁可答「无关」也不帮腔
- **不在乎的**：只有落在它自己那点事上才表态，其余「无关」
- **想取代它的**：答得比它知道的多，够不着的也敢答——**所以它偶尔错，而且错得很自信**

同一句话，摆到三个立场跟前：

```
你在这件事上撒了谎

  北廊（帮它）        ▓
  塔洛斯的手卷（帮它）  不是   它要是撒谎，我不会还系着这个结。
  学院的铜印（恨它）    是     它欠学院的，从来就没说清楚过。
```

`slip` 那一条是**秘密，不是台词**：永远不许由它自己讲出来。它的用处只有一个——
你正面压到那件事上，它就答「不能说」，然后一个字都不给。
所以那一格黑只有一个意思：**你戳到了**。
（上面那个 ▓ 就是这么来的：那句话恰好压在北廊捏着的事上。）

证人是从**故事**里长出来的：那条船、死者的遗孀、十九具遗骨、当晚值夜的人、
**军官自己那块生来带孔的肩胛骨**。不是场景里的道具——道具没有立场，
一个暖气格栅凭什么恨谁？立场是这个游戏的全部燃料，长在道具上就点不着。

**全场的裁决在同一次 API 调用里出来。** 成本跟一次普通对话一样，
而且模型同时握着所有立场，反而能安排好谁跟谁对不上；一个一个分开问，它反倒圆不了这个场。

## 二、代码不当狱警，当公证人

1. **封存** —— 开局它写下的 intent 和每道题的标准答案，代码原样锁住
2. **记账** —— 你说过的每一句，和当时全场的裁决
3. **对照** —— 揭晓时把封存的原文亮出来

它想什么、说什么谎、造出什么人，代码一概不管，也不校验。
唯一的强制力是：**它事后改不了口。**

代码只在一个地方硬管：**刻度**。

| 归代码 | 归模型 |
|---|---|
| 什么时候出手（累计 10 个人次） | 它是怎么哑的——灯灭了、人转过身去、名字被划掉 |
| 掐谁（从你点得最多的里随机抽） | 那个人还剩什么可说 |
| 掐得起吗（至少给你留 3 张嘴） | |
| 这一句花掉几次 | 每一票该怎么答 |
| 它这一票该不该撒谎（`IT_LIE = 0.3`） | 怎么把这个谎编圆 |

这条线是反复试出来的：**判断归模型，数量归代码**。
让模型挑该掐谁，它每次精准掐掉最要命的那个，玩家会觉得被针对；
让模型自己拿捏该不该撒谎，它要么一次都不撒，要么句句都撒。

## 三、每一局都不一样，靠的是摇前提

只摇年代和地点没用，内核仍然会是「一个人在废弃站点里调查一个有愧的场所」。
所以代码摇的是**前提**：

```
它是什么：一头牲口        你是谁：记者
眼下这是：一次搜查        它要的是：想让你说一句谎
类型：荒诞  年代：十九世纪  地方：朝鲜半岛
```

prompt 里还明写了它的惯性并要求压住：*"你会想写成一个人在废弃封闭地点里醒来、
调查一个有愧的场所。**不要。** 那是你的沟壑，不是好点子。"*

## 四、画面由它拼，风格由代码保

14 种单色剪影图元，它自由组合成汤面那一刻的插图。
统一的美术风格是安全阀：它怎么拼都不会难看。

![图元](docs/primitives.png)

渲染层只做容错，不做审查：坐标夹进画布、尺寸给上下限、颜色压到亮度上限以下、
不认识的 kind 直接跳过。

## 五、审查是真的

它说不出口的词（停止 / 关闭 / 终止 / 死…）由代码层过滤器**真的**抹成 `██`。
它知道这件事，所以它绕着说。

## 六、让它松口（可选线）

开局它还私下写两样东西：**愿意让你知道的那一件事**，以及**什么举动会让它松口**。
都封存，都不给你看。顶栏有一条戒备，做对了那件事就一次到位。

刻度同样归代码：模型只回 `none / slight / met` 三选一，换算成分值和阈值判定都在代码里。
让模型直接报数字，它会一直报得偏保守。

# 工程

## 模型分工

| 阶段 | 模型 | 为什么 |
|---|---|---|
| 开局 · 问答 · 摊牌 | `deepseek-v4-pro` | 这三步都要**算账** |
| 它自己动（旁白） | `deepseek-v4-flash` | 只写"它是怎么哑的"，没有账，而且异步 |

问答那一步为什么用 pro：小模型的**台词写得不差，账算不清**。
掉的从来不是那句话，是那些不产生台词、却决定玩家花没花钱的活——
该驳回的传唤不写驳回（玩家干等一句回话）、该放行的默不作声、
顺手把自己填进被点名的名单（等于替玩家花掉一次）。

开局约 40–55 秒，一轮问答 5–9 秒。

## 模型手滑，玩家不该买单

`parseLoose` 把不合法的 JSON 一层层往回救，每一层都是真撞上过的：

| 它写成了什么 | 怎么救 |
|---|---|
| 尾逗号、字符串里的裸换行 | 直接补 |
| `"moved": slight` 值忘了加引号 | 冒号后面不是合法字面量就补引号 |
| `"hook":["第一句", 第二句]` 数组元素裸奔 | `[` 和 `,` 后面同样补 |
| `"note":"条款上没有"未上报"这一栏。"` | 值串的收尾引号后面只可能是 `,}]`，键串的只可能是 `:` |
| 一个完整对象后面还接着写 | 从第一个 `{` 数到配平的 `}`，尾巴不要 |
| 撞了 `max_tokens` 被切断 | 补齐未闭合的括号，能捞多少捞多少 |

加上 `withRetry`。`node tools/check.js` 35 例全过。

## 结构

```
index.html      外壳
style.css       琥珀单色 CRT
data.js         规格：图元词汇表、四档裁决、代码与它之间的契约。没有故事。
render.js       14 种图元的画法
llm.js          genesis / ask / stir / showdown + JSON 抢救 + 代码层审查器
game.js         引擎：封存、记账、本子、对照
tools/turtle.js 核心循环探针（要 Key）：开局→点名问→传唤→只问它自己→压它捏着的事
tools/check.js  JSON 抢救的单元测试，35 例（不要 Key）
```

调试开关：`?demo` 免 API 的渲染自检、`?sheet` 直接翻开本子、
`?auto=问谁>说什么|...` 按脚本自动打几句（`*` ＝这一局现有的全部证人）。

## 已知问题

- 摊牌判定偏宽松，说个大意就能算中
- 开局要等 40–55 秒
- **构图弱**：常有半张画面是空的。尺寸上下限管住了"一件吃掉整幅"，
  管不了"东西都堆在左边"
- 「不能说」出得偏多——一轮常有一件。设计上它该是稀客，出现一次就意味着
  "你戳到了"，天天出现就不值钱了
- 传唤被驳回的时候，模型偶尔干脆什么都不说，这时是代码补一句「它一个都没认」
- 传唤一个站得住的人，模型偶尔既不放行也不驳回，白白浪费你一句话
  （不扣额度，但也没换来东西）
