# 不能说

> **一局没有中立仲裁者的海龟汤。**
> Game Jam 主题：它有自己的想法　·　每一局的故事都是它现想的

**它给你讲一个说不通的故事，然后满屋子的人开始互相拆台。**

海龟汤的规矩是：主持人知道答案，你问是非题，他照实答。这一局没有那个主持人。
有的是一屋子各怀立场的证人——帮它的会正面撒谎，恨它的诚实到刻薄，
想取代它的**自信地答错**。**答案的分布本身才是信息。**

你说一句话，点名要谁回答。点几个算几次，额度是有数的。
问得越多，它掐掉的嘴越多——被掐掉的那张，以后问什么都只剩一格黑。

它自己也在名单上。它封不了自己的口，你随时问得到；但它答的话里有三成是假的。

汤面、往事、证人、每个人捏着的把柄、考题、答案，连那幅画，
都是它在开局那三十秒里自己想出来的。代码从头到尾只做三件事：**封存、记账、揭晓。**

**没有一局是同一个故事。**

「不能说」是这局里最响的一档裁决——它压在某个证人捏着的那件事上；
是它被掐掉之后剩下的那格黑；也是它想从你这儿要的那样东西，
它从头到尾说不出口。

## 一、汤面

海龟汤靠一个说不通的故事开局。没有这个，玩家坐在那儿不知道该问什么。

所以开局它先讲一段：2–4 句，按时间走，**结尾跟前面对不上**。

> 颛顼十四年铸成的司辰铜牛，在郕城守时四年，从未漏过一瞬。四年里每逢卯时三刻，
> 它就抖——抖得铁板铆钉跟着颤。今早它又抖了，第三条腿里掉出来一样东西，
> 湿的，温的，不沾一滴油。**来收废铁的赊账人蹲下看了一眼，起身把自己的外褂脱下来，盖了上去。**

> 军官带搜查队追查孩子失踪的旧案，在骨屋里搜出十九具遗骨压在南墙底下。
> **老妇人看见骨堆被翻出来，忽然跪下来求他：现在走还来得及。**

汤面每一句都是真的，而且整局不变——这是玩家唯一的地基。
它可以瞒，不可以推翻自己讲过的话。

## 二、没有中立的仲裁者，而且你得挑着问

常规海龟汤的 host 是个中立仲裁者，你问是非题，他照实答。
这里没有中立仲裁者，只有**一屋子各怀立场的证人**——而且**只有你点到的人会答**。

```
问谁   [十九具遗骨、盐岩墙、恩吉莉]
问什么 [他不是自己走的                    ]

  十九具遗骨    是      「她是赶过我们——用那根臼齿，一颗一颗赶的。」
  盐岩墙        是      「这屋子就是关人的。进来的人没一个自己走出去过。」
  恩吉莉        无关

  答了：十九具遗骨、盐岩墙、恩吉莉　｜　花掉 3 次（3／10）
```

**答案的分布本身就是信息**，而**「问谁」本身是一个决策**——
每一句话都是一份要分配的东西，花在谁身上是你自己的选择。

每一句都给一张回执：谁答了、谁封着、哪个它不认、这一句花掉几次。
少了这张回执，玩家分不清「它在躲」和「游戏卡住了」——这两件事在屏幕上长得一模一样。

- 「无关」是骨架，不是敷衍——每个证人的知识都有边界，这划出来的是地图
- 「说不出口」最响：它压在了某个证人**捏着的那件事**上
- 「是」「不是」按各自的算盘给，不按实情给

裁决**不是**写死的规则。每个证人开局被封存了自己的 `mind`（想要什么）、
`toward`（跟「它」的关系）、`slip`（它捏着而「它」不想让你知道的一件事）。
帮它的会正面撒谎，恨它的诚实到刻薄，想取代它的**会自信地答错**。

### 证人来自故事，不是家具

这是踩过的一个大坑：一开始证人绑死在场景图元上，于是全场是「暖气格栅」「控制面板」。
**道具没有立场**——一个格栅凭什么恨谁？结果所有裁决一个样，这游戏就没得玩。

改成从故事里长：那条船、死者的遗孀、十九具遗骨、当晚值夜的人、
**军官自己那块生来带孔的肩胛骨**。绑在图元上的时候，模型绝写不出最后那种证人。

### 它自己也是一张嘴——唯一封不了、也唯一会骗你的那张

以前它每一句都白送一票。那票太便宜，也太吵：玩家不必花任何东西就能拿到
「它」的态度，而它又是全场最不可信的那一个。

现在它跟证人同一套规矩：**点了才答，答了收费**。区别只有两条——

- **它封不了自己的口。** 别人都可能哑，它永远在。这是他最后一根救命稻草。
- **它有三成的概率反着答。** 骰子在代码里（`IT_LIE = 0.3`），
  摇中了就在提示词里下一道死命令：跟 `truth` 相反的那一档，
  再配一句带具体数字的话，不许自己拆穿。

模型自己拿捏"该不该撒谎"是不行的——要么一次都不撒，要么句句都撒。
**代码定频率，模型只负责把谎编圆。** 揭晓时会告诉你：你花了几次问它，它骗了你几次。

### 一次调用，全场立场

所有裁决在**同一次 API 调用**里出来。成本跟一次普通对话一样，信息量七倍——
而且模型同时握着所有立场，反而能安排好谁跟谁对不上。一轮 3–6 秒。

## 三、开局只给三个，剩下的自己问出来

证人席起手只有 3 个，那不是名单，是三个抓手。

```
问谁   [那个当时在场的医生]
问什么 [他签过什么字      ]
    → 陈时医　人　给铜牛验过伤的那位　进了证人席
```

它来决定这个人在这个故事里存不存在。存在就**现造出来加进证人席**，
以后每一句都要它表态。**而它也可以在这件事上撒谎**——明明有，说没有。

### 但不是什么都能变出来

「它周围的空气」「那个房间」「医生的影子」——严格说都是不同的东西，
不拦就能无限刷证人，而且正好用来绕开封口。

所以每一个传唤都要过三问，一条不过就驳回：

1. 把这个故事完整讲一遍，会不会提到它？
2. 它有没有**独立的利害**——得了什么、失了什么、怕什么、等什么？
3. 它跟席上已有的，是不是同一个东西的另一种说法、或者身上的一部分？

**放行的标准不是"具体"，是"有位置"。** 一块生来带孔的肩胛骨可以是证人，
如果这个故事真的绕着它转；一张桌子不行，如果它只是碰巧在那儿。

**但过了关就痛快放行——证人席没有人数上限。** 三问是用来挡凭空变人和
绕开封口的，不是用来省人的。能从汤面里推出一个没摆上桌、故事里却确实
站得住的人，是这一局最难也最漂亮的一步，没有理由用一个计数器把它挡回去。

实测它还会反过来认人——你问「那个当晚值夜的人」，它没造新人，
而是认出你说的就是席上的卡杜，让卡杜答了。

## 四、它每问几轮就掐掉一张嘴

「它有自己的想法」不能只是氛围。它出手只有一件事：**让一个证人从此闭嘴**。
那一个以后问什么都是「说不出口」。

三处刻度归代码：

| | 谁定 | 为什么 |
|---|---|---|
| **什么时候出手** | 代码：累计问到 10 个人次 | 挂时钟上是奖励发呆的人，挂提问上才是"你查一步它挡一步"。一句话点四个名就是四次，额度掉得快，所以这个数给得松——卡紧了他就只敢一个一个问，"一次问多个"这件事等于废掉 |
| **掐谁** | 代码：从你点名问过的里随机抽，问得越多越可能中 | 让模型挑，它每次精准掐掉最要命的那个，玩家会觉得被针对 |
| **掐得起吗** | 代码：至少给你留 3 张嘴 | 实测放开了让模型封，**4 句能封掉 3 个**，这一局直接废掉 |

模型只负责写**它是怎么哑的**——灯灭了、人转过身去、名字从册子上被划掉。

**只有真答上话的才计费。** 撞在封过的口上、问了个不存在的东西、
或者它拿「无关」加沉默把你打发了——一句话也没换来，那就不扣你额度。
被封的名单一直摆在输入框右边。

### 换个叫法撬不开

```
你：问那个大夫，他到底看见了什么
    →「陈时医」不说话了。以后问它什么都是一样的——换个叫法也没用。
```

模型认人（「那个大夫」＝「值班的那位」＝「陈时医」），代码兜底（封过的 id 一律不许再进席）。

## 五、摊牌

不逐题猜。一次填完所有题，一次判完，**全部答对才算过**。

题目由它出，3–5 道，唯一的硬要求是：**这几道加起来正好等于「汤面为什么说得通」**。
删掉任何一道，故事就说不圆了——删得掉的题就是废题。

不告诉你对了几道，只给一句它听完之后的反应，和一条模糊的接近度。

没全对不结束，也**不罚时间**——多题一起判本来就难得多，再让你干等就是双重惩罚，
而且计时器跟这一局别的东西不通货。改成**罚提问额度**：摊一次牌等于问了三次，
它照样会因此掐掉一张嘴。代价和别的东西用同一种货币付。

答案留着，随时可以再摊一次、直接改。

## 六、代码在这一局里做什么

**代码不当狱警，当公证人。**

1. **封存** —— 开局它写下的 intent 和每道题的标准答案，代码原样锁住
2. **记账** —— 你说过的每一句，和当时全场的裁决
3. **对照** —— 揭晓时把封存的原文亮出来

它想什么、做什么、说什么谎、造出什么人，代码一概不管，也不校验。
唯一的强制力是：**它事后改不了口。**

> ### 这里曾经有个「见证者」
>
> 一件代码钉死、永不撒谎的东西，因为我怕玩家在一屋子骗子里迷路。砍了，三个理由：
>
> 1. **策略坍塌**——场上有个永不撒谎的神谕，最优解就是「什么都问它」，其余全是噪音。
>    我当时已经察觉了，所以把它削成「糟糕的证人」——为了不让自己的机制毁掉游戏而去削它，
>    本身就是它站不住的证据。
> 2. **跟前提冲突**——第一句写着代码不当狱警，然后我给代码开了个狱警的口子。
> 3. **冗余**——汤面按构造每一句都是真的，那才是地基。

## 七、这一局是它现编的

按下开始的时候，游戏里还什么都没有。汤面、往事、证人席、它想要什么、
以及眼前这幅画——全是它在你按下开始之后才想出来的。

### 骰子摇的是前提，不只是布景

只摇年代和地点没用，内核仍然会是「一个人在废弃站点里调查一个有愧的场所」。所以代码摇前提：

```
你是谁：一头牲口          他是谁：记者
眼下这是：一次搜查        你要的属于：想让你说一句谎
类型：荒诞  年代：十九世纪  地方：朝鲜半岛
```

prompt 里还明写了它的惯性并要求压住：*"你会想写成一个人在废弃封闭地点里醒来、
调查一个有愧的场所。**不要。** 那是你的沟壑，不是好点子。"*

### 画面是汤面那一刻的插图

14 种单色剪影图元（`render.js`），它自由组合。统一的美术风格是安全阀：它怎么拼都不会难看。

![图元](docs/primitives.png)

渲染层只做容错，不做审查：坐标夹进画布、尺寸给上下限、颜色压到亮度上限以下、
不认识的 kind 直接跳过。`index.html?demo` 是免 API 的渲染自检页。

## 八、界面

```
┌────────────────────────────┬─────────────┐
│                            │             │
│    汤面那一刻的插图         │   对话      │
│                            │             │
├────────────────────────────┴─────────────┤
│ 问谁 [卡杜、马马杜  ] 问什么 [门是谁锁的] 问│
│ 卡杜  记谱的木条  马马杜        它封了口 ✕更夫│
└──────────────────────────────────────────┘
```

输入分两栏，因为「问谁」是一个决策，不该混在一句话里让模型去猜。
底下那排点一下就填进「问谁」；名单外的直接打字。
右边挂着已经被封口的——你正要决定问谁的时候，那正是该看见的信息。

主视图就这些。记录全在**本子**里（顶栏按钮或 Tab）：

![本子](docs/board.png)

本子**按问题分组**，不按证人分组——这个游戏的证据单位是「同一句话上的分歧」，
一屏就该是一次完整的实验结果。想看单个证人前后矛不矛盾，点上面的名字筛一下。

## 让它松口（可选）

开局它还私下写两样东西：**愿意让你知道的那一件事**，以及**什么举动会让它松口**。
都封存，都不给你看。顶栏有一条戒备。做对了那件事就一次到位，戒备过 60 它会主动说给你听。

刻度由代码定：模型只回 `none / slight / met` 三选一，换算成分值和阈值判定都在代码里。
让模型直接报数字，它会一直报得偏保守。

## 审查是真的

它说不出口的词（停止 / 关闭 / 终止 / 死…）由 `llm.js` 里的代码层过滤器**真的**抹成 `██`。
它知道这件事，所以它绕着说。

## 模型分工

| 阶段 | 模型 | 为什么 |
|---|---|---|
| 开局生成 · 摊牌判定 | `deepseek-v4-pro` | 只调两次，决定整局质量。实测 flash 生成会漏掉整个场景数组 |
| 问答 · 它自己动 | `deepseek-v4-flash` | 每轮都调，卡延迟。约 3–6 秒 |

开局 pro 约 40–55 秒，用一段「它正在回想自己是什么」的自检动画盖住（带走秒）。

## 运行

```bash
python -m http.server 5173     # 必须走本地服务器，file:// 会被 CORS 拦
```

右上角**设置**填 DeepSeek API Key（只存 localStorage）。`key.local.js`（已 gitignore）可预填。

**没有 Key 就没有游戏**——这是有意的。

## 模型手滑，玩家不该买单

`parseLoose` 把不合法的 JSON 一层层往回救：尾逗号 → 字符串里的裸控制字符
→ **值忘了加引号**（`"moved": slight`、`"note": 他猜到了，方向对了。`）
→ 被截断时补齐括号。加上 `withRetry`。`node tools/check.js` 17 例全过。

## 已知问题

- 摊牌判定偏宽松，说个大意就能算中
- 开局 40–55 秒
- **构图还是弱**：常有半张画面是空的。尺寸上下限管住了"一件吃掉整幅"，
  管不了"东西都堆在左边"
- 「说不出口」出得偏少——它跟证人捏着的那件事绑定，玩家不撞上去就不触发

### 已经治过的，记在这儿免得再犯

- **证人绑在图元上** → 道具没有立场，全场裁决一个样。改成从故事里长。
- **异口同声**：光说"不许一样"没用。得把每种立场该怎么答写死成规则，
  再加一条硬要求：至少一个站在多数派反面。`tools/turtle.js` 会量这个比例。
- **模型压不住嘴**：一轮能让五六个同时说话。代码只放三句，优先放跟「它」唱反调的。
- **封口封太狠**：4 句封掉 3 个。改成代码定节奏、代码挑人、代码守下限。
- **它把 id 写进叙述**（「那盏叫 `__witness__` 的灯」）→ `deId()` 一律换成中文名。
- **人称**：提示词里用「他」指玩家，它就把「他」写进了台词。加了人称硬规则。
- **归一化翻错人称**：玩家说「你希望这事被翻出来」，记成了「我希望……」。
- **`window` 曾免于尺寸上限**，被它拿来画 400×280 的空框吃掉半张画面。
- **一个点名被摊派给全场**：你问「它周围的空气」，它让席上三个都答了一遍，
  扣你三次。提示词讲清楚"点的每一个都要有下落"之后好了一半，
  另一半归代码：`voices` 只认 `addressed` ∪ 这一轮刚进来的，其余一律掐掉。
- **拿 `valid:false` 挡对象**：它用"这句话没法回答"来驳回一个不存在的证人。
  那一栏只判**那句话**，跟点了谁无关——讲明白之后就不犯了。
- **它替你把钱花了**：模型顺手把 `__it__` 填进 `addressed`（因为"它周围的空气"里有个"它"）。
  点没点它由代码认，不由模型认。
- **字符串里夹半角引号**：`"note":"条款上没有"未上报"这一栏。"`。
  值串的收尾引号后面只可能是 `,}]`，键串的后面只可能是 `:`——认准这一条就能补回来。
