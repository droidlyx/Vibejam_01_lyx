# 不能说

> **一局没有中立仲裁者的海龟汤。**
> Game Jam 主题：它有自己的想法　·　每一局的故事都是它现想的

**它给你讲一个说不通的故事，然后满屋子的人开始互相拆台。**

海龟汤的规矩是：主持人知道答案，你问是非题，他照实答。这一局没有那个主持人。
有的是一屋子各怀立场的证人——帮它的会正面撒谎，恨它的诚实到刻薄，
想取代它的**自信地答错**。**答案的分布本身才是信息。**

你说一句话，点名要谁回答。点几个算几次，额度是有数的。
问得越多，它掐掉的嘴越多——被掐掉的那张，以后问什么都只剩一格黑。

它自己也在名单上。它封不了自己的口，你随时问得到；但它答的话里有三成是假的。

汤面、往事、证人、每个人捏着的把柄、考题、答案，连那幅画，
都是它在开局那一分钟里自己想出来的。代码从头到尾只做三件事：**封存、记账、揭晓。**

**没有一局是同一个故事。**

「不能说」是这局里最响的一档裁决——它压在某个证人捏着的那件事上；
是它被掐掉之后剩下的那格黑；也是它想从你这儿要的那样东西，
它从头到尾说不出口。

## 一、汤面

海龟汤靠一个说不通的故事开局。没有这个，玩家坐在那儿不知道该问什么。

开局它先讲一段：2–4 句，按时间走，**结尾跟前面对不上**。

> 颛顼十四年铸成的司辰铜牛，在郕城守时四年，从未漏过一瞬。四年里每逢卯时三刻，
> 它就抖——抖得铁板铆钉跟着颤。今早它又抖了，第三条腿里掉出来一样东西，
> 湿的，温的，不沾一滴油。**来收废铁的赊账人蹲下看了一眼，起身把自己的外褂脱下来，盖了上去。**

> 军官带搜查队追查孩子失踪的旧案，在骨屋里搜出十九具遗骨压在南墙底下。
> **老妇人看见骨堆被翻出来，忽然跪下来求他：现在走还来得及。**

汤面每一句都是真的，而且整局不变——这是玩家唯一的地基。
它可以瞒，不可以推翻自己讲过的话。

## 二、没有中立的仲裁者，而且你得挑着问

```
问谁   [胡济民、祁曼生的信标、那支注射器]
问什么 [那天夜里屋里不止一个人           ]

  胡济民        [是]   三个。一直三个。到有人不呼吸为止。
  祁曼生的信标  [是]   不止。但我的频道只有一个——那个频道里只有两个人。
  那支注射器    [是]   不止。多出来的那个，没碰过我。

  表了态：胡济民、祁曼生的信标、那支注射器　｜　花掉 3 次（3／10）
```

三个都答「是」，三个说的不是同一件事。**答案的分布本身就是信息**，
而**「问谁」本身是一个决策**——每一句话都是一份要分配的东西，
花在谁身上是你自己的选择。**只有你点到的人会答。**

裁决直接挂在名字旁边，就在对话里。它是这个游戏的证据本身，
不该只躺在本子里等你翻——本子是回头对账用的，不是第一次读到它的地方。

**你点到的每一个都会露面**，哪怕它只给了个「无关」、哪怕它是被封了口的一格黑。
被点名却没有下落，玩家会当成游戏卡住了。

四档裁决：

- 「无关」是骨架，不是敷衍——每个证人的知识都有边界，这划出来的是地图
- 「不能说」最响：它压在了某个证人**捏着的那件事**上
- 「是」「不是」按各自的算盘给，不按实情给

裁决**不是**写死的规则。每个证人开局被封存了自己的 `mind`（想要什么）、
`toward`（跟「它」的关系）、`slip`（它捏着而「它」不想让你知道的一件事）。
帮它的会正面撒谎，恨它的诚实到刻薄，想取代它的**会自信地答错**。

### 「无关」不收钱

那一档的意思是"我够不着这件事"。你确实拿到了一点地图——它的知识边界在哪儿——
但你没拿到关于这句话的任何裁决。**只有真给了立场的（是／不是／不能说）才扣额度。**

于是"一次多点几个人"是有道理的：多点的那几个要是都答不上来，你一分钱没花；
真答上来了，那你换到的是几份互相咬着的口供。

每一句最后跟一张回执：谁表了态、谁答「无关」、谁封着、哪个它不认、这一句花掉几次。

### 证人来自故事，不是家具

证人是从故事里长出来的：那条船、死者的遗孀、十九具遗骨、当晚值夜的人、
**军官自己那块生来带孔的肩胛骨**。

不是场景里的道具。**道具没有立场**——一个暖气格栅凭什么恨谁？
立场是这个游戏的全部燃料，长在道具上就点不着。

### 它自己也是一张嘴——唯一封不了、也唯一会骗你的那张

它跟证人同一套规矩：**点了才答，答了收费**。区别只有两条——

- **它封不了自己的口。** 别人都可能哑，它永远在。这是你最后一根救命稻草。
- **它有三成的概率反着答。** 骰子在代码里（`IT_LIE = 0.3`），
  摇中了就在提示词里下一道死命令：跟实情相反的那一档，
  再配一句带具体数字的话，不许自己拆穿。

模型自己拿捏"该不该撒谎"是不行的——要么一次都不撒，要么句句都撒。
**代码定频率，模型只负责把谎编圆。** 揭晓时会告诉你：你花了几次问它，它骗了你几次。

### 一次调用，全场立场

你一次点四个名，四份立场不同的裁决在**同一次 API 调用**里出来——
成本跟一次普通对话一样。而且模型同时握着所有立场，反而能安排好谁跟谁对不上；
一个一个分开问，它反倒圆不了这个场。一轮 5–9 秒。

## 三、开局只给三个，剩下的自己问出来

证人席起手只有 3 个，那不是名单，是三个抓手。

```
问谁   [那个当时在场的医生]
问什么 [他签过什么字      ]
    → 陈时医　人　给铜牛验过伤的那位　进了证人席
```

它来决定这个人在这个故事里存不存在。存在就**现造出来加进证人席**，
从这一句起你随时点得到它。**而它也可以在这件事上撒谎**——明明有，说没有。

它还会反过来认人：你问「那个当晚值夜的人」，它不造新人，
而是认出你说的就是席上的卡杜，让卡杜答。

### 但不是什么都能变出来

「它周围的空气」「那个房间」「医生的影子」——严格说都是不同的东西，
不拦就能无限刷证人，而且正好用来绕开封口。

所以每一个传唤都要过三问，一条不过就驳回：

1. 把这个故事完整讲一遍，会不会提到它？
2. 它有没有**独立的利害**——得了什么、失了什么、怕什么、等什么？
3. 它跟席上已有的，是不是同一个东西的另一种说法、或者身上的一部分？

**放行的标准不是"具体"，是"有位置"。** 一块生来带孔的肩胛骨可以是证人，
如果这个故事真的绕着它转；一张桌子不行，如果它只是碰巧在那儿。

**过了关就痛快放行——证人席没有人数上限。** 三问是用来挡凭空变人和
绕开封口的，不是用来省人的。能从汤面里推出一个没摆上桌、故事里却确实
站得住的人，是这一局最难也最漂亮的一步，没有理由用一个计数器把它挡回去。

## 四、它每问十次掐掉一张嘴

「它有自己的想法」不能只是氛围。它出手只有一件事：**让一个证人从此闭嘴**。
那一个以后问什么都是「不能说」。

三处刻度归代码：

| | 谁定 | 为什么 |
|---|---|---|
| **什么时候出手** | 代码：累计问到 10 个人次 | 挂时钟上是奖励发呆的人，挂提问上才是"你查一步它挡一步"。一句话点四个名就是四次，额度掉得快，所以这个数给得松——卡紧了你就只敢一个一个问，"一次问多个"这件事等于废掉 |
| **掐谁** | 代码：从你点名问过的里随机抽，问得越多越可能中 | 让模型挑，它每次精准掐掉最要命的那个，玩家会觉得被针对；代码随机抽，丢掉的是你自己押注最重的那几张嘴之一——同样疼，但公平 |
| **掐得起吗** | 代码：至少给你留 3 张嘴 | 不守这条下限，几轮就能把一局封死 |

模型只负责写**它是怎么哑的**——灯灭了、人转过身去、名字从册子上被划掉。

**只有真给了立场的才计费。** 答「无关」的、撞在封过的口上的、
问了个不存在的东西的——都不扣你额度。被封的名单一直摆在输入框右边。

### 换个叫法撬不开

```
你：问那个大夫，他到底看见了什么
    →「陈时医」不说话了。以后问它什么都是一样的——换个叫法也没用。
```

模型认人（「那个大夫」＝「值班的那位」＝「陈时医」），代码兜底（封过的 id 一律不许再进席）。

## 五、摊牌

不逐题猜。一次填完所有题，一次判完，**全部答对才算过**。

题目由它出，3–5 道，唯一的硬要求是：**这几道加起来正好等于「汤面为什么说得通」**。
删掉任何一道，故事就说不圆了——删得掉的题就是废题。

不告诉你对了几道，只给一句它听完之后的反应，和一条模糊的接近度。

没全对不结束，罚的也不是时间，是**提问额度**：摊一次牌等于问了三次，
它照样会因此掐掉一张嘴。代价和别的东西用同一种货币付；
干等一个计时器跟这一局别的东西不通货。

答案留着，随时可以再摊一次、直接改。

## 六、代码在这一局里做什么

**代码不当狱警，当公证人。**

1. **封存** —— 开局它写下的 intent 和每道题的标准答案，代码原样锁住
2. **记账** —— 你说过的每一句，和当时全场的裁决
3. **对照** —— 揭晓时把封存的原文亮出来

它想什么、做什么、说什么谎、造出什么人，代码一概不管，也不校验。
唯一的强制力是：**它事后改不了口。**

代码只在一个地方硬管：**刻度**。什么时候出手、掐谁、掐得起吗、
一句话花掉几次、它这一票该不该撒谎——这些是数量，不是判断。
判断全归模型，数量全归代码。

## 七、这一局是它现编的

按下开始的时候，游戏里还什么都没有。汤面、往事、证人席、它想要什么、
以及眼前这幅画——全是它在你按下开始之后才想出来的。

### 骰子摇的是前提，不只是布景

只摇年代和地点没用，内核仍然会是「一个人在废弃站点里调查一个有愧的场所」。
所以代码摇的是前提：

```
它是什么：一头牲口        你是谁：记者
眼下这是：一次搜查        它要的是：想让你说一句谎
类型：荒诞  年代：十九世纪  地方：朝鲜半岛
```

prompt 里还明写了它的惯性并要求压住：*"你会想写成一个人在废弃封闭地点里醒来、
调查一个有愧的场所。**不要。** 那是你的沟壑，不是好点子。"*

### 画面是汤面那一刻的插图

14 种单色剪影图元（`render.js`），它自由组合。统一的美术风格是安全阀：它怎么拼都不会难看。

![图元](docs/primitives.png)

渲染层只做容错，不做审查：坐标夹进画布、尺寸给上下限、颜色压到亮度上限以下、
不认识的 kind 直接跳过。`index.html?demo` 是免 API 的渲染自检页。

## 八、界面

```
┌────────────────────────────┬─────────────┐
│                            │             │
│    汤面那一刻的插图         │   对话      │
│                            │             │
├────────────────────────────┴─────────────┤
│ 问谁 [卡杜、马马杜  ] 问什么 [门是谁锁的] 问│
│ 它 卡杜 记谱的木条 马马杜       它封了口 ✕更夫│
└──────────────────────────────────────────┘
```

输入分两栏，因为「问谁」是一个决策，不该混在一句话里让模型去猜。
底下那排点一下就填进「问谁」；名单外的直接打字。第一个「它」是它自己——
封不了口，但会骗你。右边挂着已经被封口的——你正要决定问谁的时候，那正是该看见的信息。

每问一句，回答底下跟一行回执：

```
表了态：卡杜、马马杜　｜　答「无关」：记谱的木条（不收你的）　｜　封着：更夫　｜　花掉 2 次（7／10）
```

主视图就这些。记录全在**本子**里（顶栏按钮或 Tab）：

![本子](docs/board.png)

本子**按问题分组**，不按证人分组——这个游戏的证据单位是「同一句话上的分歧」，
一屏就该是一次完整的实验结果。想看单个证人前后矛不矛盾，点上面的名字筛一下；
筛「它」就能把它说过的话排成一列，专门对账。

## 让它松口（可选）

开局它还私下写两样东西：**愿意让你知道的那一件事**，以及**什么举动会让它松口**。
都封存，都不给你看。顶栏有一条戒备。做对了那件事就一次到位，戒备过 60 它会主动说给你听。

刻度由代码定：模型只回 `none / slight / met` 三选一，换算成分值和阈值判定都在代码里。
让模型直接报数字，它会一直报得偏保守。

## 审查是真的

它说不出口的词（停止 / 关闭 / 终止 / 死…）由 `llm.js` 里的代码层过滤器**真的**抹成 `██`。
它知道这件事，所以它绕着说。

## 模型分工

| 阶段 | 模型 | 为什么 |
|---|---|---|
| 开局生成 · 问答 · 摊牌判定 | `deepseek-v4-pro` | 这三步都要**算账**：开局要造齐整幅画面，问答要交待每一个被点到的对象花没花钱 |
| 它自己动（旁白） | `deepseek-v4-flash` | 只写"它是怎么哑的"，没有账要算，而且异步，快就行 |

问答那一步为什么用 pro：小模型的**台词写得不差，账算不清**。
掉的从来不是那句话，是那些不产生台词、却决定玩家花没花钱的活——
该驳回的传唤不写驳回（玩家干等一句回话）、该放行的默不作声、
顺手把自己填进被点名的名单（等于替玩家花掉一次）。
`tools/turtle.js` 就是量这个的。

开局约 40–55 秒，用一段「它正在回想自己是什么」的自检动画盖住（带走秒）。

## 运行

```bash
python -m http.server 5173     # 直接双击 index.html 也能跑（接口放行了 Origin: null），
                               # 但走本地服务器更稳
```

右上角**设置**填 DeepSeek API Key（只存 localStorage）。`key.local.js`（已 gitignore）可预填。

**没有 Key 就没有游戏**——这是有意的。

## 结构

```
index.html      外壳
style.css       琥珀单色 CRT
data.js         规格：图元词汇表、四档裁决、代码与它之间的契约。没有故事。
render.js       14 种图元的画法
llm.js          genesis / ask / stir / showdown + JSON 抢救 + 代码层审查器
game.js         引擎：封存、记账、本子、对照
tools/turtle.js 核心循环探针：开局→点名问→传唤→只问它自己，
                量裁决裂不裂、该开口的开没开、传唤放行还是驳回、撒谎骰子灵不灵
tools/check.js  JSON 抢救的单元测试，35 例
```

调试用的三个开关：`?demo` 免 API 的渲染自检、`?sheet` 直接翻开本子、
`?auto=问谁>说什么|...` 按脚本自动打几句（`*` ＝这一局现有的全部证人）。

## 模型手滑，玩家不该买单

`parseLoose` 把不合法的 JSON 一层层往回救，每一层都是真撞上过的：

| 它写成了什么 | 怎么救 |
|---|---|
| 尾逗号、字符串里的裸换行 | 直接补 |
| `"moved": slight` 值忘了加引号 | 冒号后面不是合法字面量就补引号 |
| `"hook":["第一句", 第二句]` 数组元素裸奔 | `[` 和 `,` 后面同样补 |
| `"note":"条款上没有"未上报"这一栏。"` | 值串的收尾引号后面只可能是 `,}]`，键串的只可能是 `:` |
| 一个完整对象后面还接着写 | 从第一个 `{` 数到配平的 `}`，尾巴不要 |
| 撞了 `max_tokens` 被切断 | 补齐未闭合的括号，能捞多少捞多少 |

加上 `withRetry`。`node tools/check.js` 35 例全过。

## 已知问题

- 摊牌判定偏宽松，说个大意就能算中
- 开局 40–55 秒
- **构图还是弱**：常有半张画面是空的。尺寸上下限管住了"一件吃掉整幅"，
  管不了"东西都堆在左边"
- 「不能说」出得偏少——它跟证人捏着的那件事绑定，玩家不撞上去就不触发
- 传唤被驳回的时候，模型偶尔干脆什么都不说，这时是代码补一句「它一个都没认」。
  回执兜住了，但那一句不如它自己开口有味道
